Bulk introspection helpers for exploring the loaded il2cpp domain - ports beatsaber-hook’s debug.hpp (log_classes/log_methods/log_fields/ log_properties), useful for reverse-engineering during mod development. Per-item Debug/Display impls already exist on Il2CppClass/[MethodInfo]/[FieldInfo]/ [PropertyInfo]; what’s missing without this module is a way to walk all of them at once.
