pub fn of_refs<'a, I>(items: I) -> Gc<Self>
where I: IntoIterator<Item = &'a T>, I::IntoIter: ExactSizeIterator<Item = &'a T>, 'static: 'a,

Creates an array from existing, shared references - e.g. singletons il2cpp itself owns and caches, like a System.Type’s reflection object. Unlike new, which takes each element as T::Held (Option<&mut T> for reference types, matching the exclusive access a freshly created or claimed value would have), this only ever copies each reference’s pointer into the array, so a plain shared &T is enough.
